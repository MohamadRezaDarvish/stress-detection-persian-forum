# Report and presentation figure guide

All figures are generated by:

```powershell
py -3.12 .\src\generate_report_figures.py --project-root .
```

Every chart is exported as both PNG and SVG. Use PNG for ordinary report insertion and
SVG for slides or documents where resizing quality matters.

## Recommended main-report figures

### 1. Row-normalized test confusion matrix

Files:

- `test_confusion_matrix_row_normalized.png`
- `test_confusion_matrix_row_normalized.svg`

Suggested caption:

> Locked-test confusion matrix. Color intensity is normalized separately within each
> actual class, so each row directly shows the destination of that class. Numbers give
> post count and row percentage. The model preserved Low, High and Very-High recall, while
> Moderate posts were divided mainly between Low, Moderate and High.

This should replace the original raw-count confusion matrix in the main report.

### 2. Predicted score distributions with threshold lines

Files:

- `test_score_distribution_with_thresholds.png`
- `validation_score_distribution_with_thresholds.png`

Suggested caption:

> Distribution of continuous fusion predictions grouped by authoritative true class. The
> vertical lines are the validation-calibrated prediction thresholds. Overlap around the
> first two thresholds explains the remaining Moderate-class errors, while the
> Very-High distribution is more clearly separated.

### 3. MAE before and after active-learning expansion

File:

- `mae_before_after_active_learning_grouped.png`

Suggested caption:

> Historical pre-active-learning and current post-active-learning MAE by model family.
> The transformer and fusion improved substantially, while the tabular-only model did not.
> Because the historical and current evaluations use different split sizes, label pools
> and leakage controls, this is a project-stage comparison rather than a controlled causal
> estimate of active learning.

Always retain that qualification in the report.

### 4. True versus predicted stress, colored by true class

File:

- `test_true_vs_predicted_by_class.png`

Suggested caption:

> Locked-test continuous predictions against the true stress score. Point color denotes
> the authoritative true class. Vertical dotted lines show the true-score class
> boundaries; horizontal dotted lines show calibrated prediction thresholds.

### 5. Recall against the project requirements

File:

- `recall_validation_vs_test_with_requirements.png`

Suggested caption:

> Per-class recall on validation and the one-time locked test. The dashed line gives the
> required class-specific floor. Validation passed all four constraints; the locked test
> failed only Moderate recall.

### 6. Test precision, recall and F1

File:

- `test_precision_recall_f1.png`

Suggested caption:

> Locked-test precision, recall and F1 by class. The chart makes the safety/utility
> trade-off explicit: Low and Very High were detected reliably, while Moderate remains the
> principal weakness.

### 7. Very-High threshold trade-off

File:

- `very_high_threshold_tradeoff.png`

Suggested caption:

> Validation sensitivity of Very-High precision, Very-High recall and High recall to the
> upper prediction threshold, holding the first two calibrated thresholds fixed. The
> selected threshold is shown by the vertical dotted line.

### 8. Explainability

Files:

- `feature_importance_top20_report.png`
- `shap_importance_top20_report.png`

Suggested caption:

> Global CatBoost importance and validation mean absolute SHAP contribution for the final
> hybrid fusion. The text-model prediction and the base-model mean dominate, while the
> tabular prediction and selected behavioral features provide complementary information.

### 9. Active-learning impact

Files:

- `active_learning_mae_percent_change.png`
- `mae_before_after_active_learning_grouped.png`

Suggested caption:

> Percentage change in MAE between the historical and current project stages. Negative
> values mean lower error. The comparison is descriptive because the two stages use
> different evaluation protocols.

### 10. End-to-end system diagram

Files:

- `system_pipeline_diagram.png`
- `system_pipeline_diagram.svg`

Suggested caption:

> End-to-end architecture. Leakage-safe fold ensembles produce the two base predictions;
> the hybrid fusion combines them with tabular features; calibrated thresholds produce
> per-post clinical bins; temporal aggregation supports alerts; uncertain or disagreeing
> posts enter the active-learning queue.

## Color contract

The report uses one stable class palette:

- Low: blue
- Moderate: gold
- High: orange
- Very High: rose

The same colors are used in score distributions and true-versus-predicted plots. The
row-normalized confusion matrix uses a single sequential blue scale because intensity
represents a percentage rather than class identity.
